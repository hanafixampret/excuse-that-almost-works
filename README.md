Entry for the [make.fun bounty](https://make.fun/bounty/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5): write the one line a gamer texts the boss to skip work on GTA 6 launch week.

`main.ts` writes a single excuse to `/output/entry.txt` — one line, 18 words, 94 characters:

> Sorry, the fridge people gave me an 8am to 6pm delivery window and they won't leave it outside

A boring, specific, real-world detail (an all-day appliance delivery window) instead of a wild story — the kind of text a tired manager has received before and almost believes.

Run it with Node 22+:

```sh
node main.ts
cat /output/entry.txt
```
